# Boîte à outils du modding de GTA V

## Documentation sur le modding du jeu GTA V : **[gta-subversion.eu](https://gta-subversion.eu/)**

## Expérimentations GTA V et FiveM

### Nos mods

| Mod | Fonctionnalité |
|---|---|
| [`change_ped`](https://github.com/PAD-EMD/gtamod-change-ped) | Changer le modèle du personnage, aléatoirement ou au choix |
| [`foule_throttle`](https://github.com/PAD-EMD/gtamod-foule-throttle) | Générer une foule de PNJ et la contrôler (apparence, animations) |
| [`player_position`](https://github.com/PAD-EMD/gtamod-player-position) | Afficher les coordonnées (x, y, z) du joueur |
| [`weapon_invoke`](https://github.com/PAD-EMD/gtamod-weapon-invoke) | Invoquer une arme dans la main du joueur |
| [`woopwoop_police`](https://github.com/PAD-EMD/gtamod-woopwoop-police) | Désactiver la recherche de la police |
| [`vehicle_settings`](https://github.com/PAD-EMD/gtamod-vehicle-settings) | Modifier le véhicule dans lequel est le joueur (couleurs, vitesse, adhérence, indestructibilité) |
| [`weather_and_time`](https://github.com/PAD-EMD/gtamod-weather-time) | Changer la météo et l'heure |
| [`waypoint_position`](https://github.com/PAD-EMD/gtamod-waypoint-position) | Afficher les coordonnées (x, y) du repère sur la carte |
| [`pnj_lab`](https://github.com/PAD-EMD/gtamod-pnj-lab) | Laboratoire d'expérimentation sur les PNJ (en cours de développement) |
| [`playable_camera_mod`](https://github.com/RobinMoretti/fivem-cinecam) | Caméra libre pour faire du machinima dans GTA V / FiveM |

### Les outils utilisés

#### Serveur local

- FXServer

#### Modifier les textures du jeu
